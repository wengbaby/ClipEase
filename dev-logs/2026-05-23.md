# 2026-05-23 开发日志

## 今日目标

- 继续收口预览窗口脱离后的独立窗口稳定性，优先处理窗口初始位置、屏幕边界和基础可操作尺寸。

## 已完成

- 独立预览窗口脱离后，初始 frame 会按当前屏幕可见区域进行约束，避免从大图、PDF 或文件预览拖出时窗口跑出屏幕可见范围。
- 独立预览窗口增加最小尺寸 `390x260`，防止被缩到不可操作；附着弹层仍保持原来的弹层尺寸策略，不受独立窗口最小尺寸影响。
- 更新 `scripts/verify_preview_window_performance_guards.py`，守卫独立预览最小尺寸、附着弹层尺寸复位、脱离初始 frame 屏幕可见区域约束和按可见区域交集选择屏幕。
- 修复预览窗口顶部第一次按住拖动只脱离、不移动的问题：拖拽开始时只切换窗口层级、释放附着槽位并立刻关闭主窗口，等系统窗口拖动结束后再重建独立预览内容和隐藏倒三角。
- 更新 `scripts/verify_preview_window_performance_guards.py`，守卫脱离时不能在第一次系统拖动前重建内容，必须通过拖动完成回调收尾。
- 修复从微信等其他 App 激活场景下，快捷键唤起轻贴、按空格打开预览后，第一次按住预览标题栏只激活轻贴而不能拖动的问题：预览标题栏拖拽热区现在显式接收 inactive window 的 first mouse 事件，第一次按下即可进入拖拽流程。
- 更新 `scripts/verify_preview_window_performance_guards.py`，守卫预览标题栏拖拽热区必须 `acceptsFirstMouse` 并返回 `true`。
- 完成 `V2-BACKLOG-S9-PREVIEW-COPY-TOAST-UNIFIED-001`：预览窗口顶部复制按钮现在与主窗口复制一致，普通复制、文件引用复制、文件路径 fallback 和失败结果都会显示全局 toast；成功和 fallback 仍保留 Copy 音效。
- 新增 `scripts/verify_preview_copy_feedback.py`，守卫预览复制按钮必须处理 `.copied`、`.copiedFallbackText` 和 `.failed` 三种结果，避免再次静默丢弃 fallback / 失败状态。
