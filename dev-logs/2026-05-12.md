## 今日完成

- 修复设置窗口关闭行为：红色关闭按钮和 `Command + W` 改为隐藏设置窗口，不再真正关闭窗口对象，避免触发 App 退出。
- 新增统一辅助功能权限状态 `AccessibilityPermissionState`，历史窗口和设置页共享同一权限状态。
- App 激活、设置页显示、历史窗口显示和手动刷新时会重新读取辅助功能权限。
- 设置页在权限异常时提示用户确认授权的是当前运行的 `ClipEase.app`。
- 权限页新增当前运行 App 路径显示。
- 权限页新增“显示当前 App”和“复制 App 路径”，用于排查辅助功能授权对象不一致。
- 粘贴执行链路新增明确结果：已粘贴、仅复制和失败原因。
- 图片文件缺失、图片无法读取或剪贴板写入失败时会显示具体提示，不再静默失败。
- 历史窗口粘贴/复制状态提示按文本、富文本、链接、图片和颜色区分。
- 修复自动粘贴焦点问题：历史窗口打开前记录原前台 App，自动粘贴前关闭历史窗口并重新激活原 App，再发送 `Command + V`。
- 二次修复自动粘贴焦点问题：自动粘贴前改为立即隐藏历史窗口，并将 `Command + V` 直接投递到原目标 App 进程。
- 按 Paste 的交互方式修正自动粘贴策略：底部历史窗口改为非激活面板显示，不激活轻贴、不抢走原 App 焦点；自动粘贴恢复为系统级 `Command + V`。
- 新增历史窗口全局键盘事件路由：底部窗口非激活显示时，仍可使用左右键、回车、空格、Esc、`Command + 1-9`、`Command + F/C/P` 操作。
- 键盘事件路由只在历史窗口显示期间安装，关闭或自动粘贴前立即卸载，避免影响普通输入。
- `Command + 1-9` 序号显示改为由非激活窗口事件状态驱动，保持不抢焦点时也能显示卡片序号。
- 修正搜索输入模式：历史窗口改为可成为键盘窗口的非激活面板，轻贴不激活为前台 App，也不主动切走原 App。
- 搜索、预览、卡片选择和快捷键操作都在非激活面板内完成；双击或回车粘贴时仍通过系统级 `Command + V` 落到原 App 光标位置。
- 完善搜索结果体验：搜索内容变化后自动选中第一条结果，搜索为空结果时关闭预览并阻止回车粘贴。
- 清空搜索后恢复到合理选中项，预览打开时会同步刷新预览内容。
- `Esc` 在搜索展开时先退出搜索，搜索未展开时再关闭历史窗口。
- 新增输入即搜索：历史窗口打开后直接输入可打印字符，会自动展开搜索框并把输入内容写入搜索。
- 输入即搜索保留方向键、回车、空格、Esc 和 Command 快捷键原有行为；搜索框聚焦后后续输入交给原生文本框处理，避免重复输入。
- 修正搜索 Esc 状态机：搜索有内容时先清空内容，搜索框为空时再关闭搜索框，搜索框关闭后再关闭轻贴。
- 搜索框清空按钮改为只清空内容，不再直接关闭搜索框。
- 修复输入即搜索后的选区问题：自动展开搜索框后光标停在文本末尾，不再默认选中首个字符。
- 搜索框聚焦时 Esc 仍由轻贴接管，按清空内容、关闭搜索框、关闭轻贴的顺序执行。
- 搜索框聚焦时 Delete 和 `Command + A` 回到原生文本框处理，支持回退删除和全选。
- 加强搜索框焦点：输入即搜索展开后显式让原生搜索框成为第一响应者并显示光标，避免搜索框无光标、无法回退删除或无法使用原生编辑快捷键。
- 面板级 Esc 改为派发到统一搜索状态机，避免绕过搜索清空流程直接关闭轻贴。
- 搜索框聚焦时除 Esc 和 `Command + 1-9` 外，其余编辑快捷键交给原生文本框处理。
- 搜索框光标在末尾且存在结果时，按右键、下键或回车会进入第一张结果卡片；没有结果时保留在搜索框。
- 从搜索框末尾再次输入字符会替换原搜索内容并开始新搜索；搜索框未关闭时保留搜索状态，不在粘贴时自动清空。
- 修正搜索框展开期间快捷键规则：搜索框展开或聚焦时，事件层不再拦截 `Command + 1-9`、Esc 和其他快捷键，全部优先交给搜索框/系统原生处理。
- 搜索框内 Esc 通过原生文本框取消回调进入轻贴搜索状态机，仍按清空内容、关闭搜索框、关闭轻贴的顺序执行。
- 重新对齐搜索快捷键规则：搜索框聚焦时只特殊接管 Esc 和 `Command + 1-9`；其他快捷键走原生文本框。
- `Command + 1-9` 改为直接粘贴对应结果卡片，不再只是选中卡片；粘贴后沿用自动隐藏主窗口链路。
- 搜索框有内容但未聚焦时，Esc 按主窗口规则关闭轻贴；搜索框聚焦时 Esc 才按清空内容、关闭搜索框、关闭轻贴执行。
- 主窗口显示时新增外部点击关闭：点击非主窗口位置会关闭轻贴。
- 修正搜索框展开但未聚焦时的 Esc 顺序：先关闭搜索框，再由下一次 Esc 关闭主窗口。
- 优化搜索性能：历史窗口不再在每次输入时通过计算属性反复全量构造和过滤卡片。
- 新增搜索结果缓存状态，输入变化后使用可取消任务防抖，再在后台线程过滤结果，主线程只应用最新结果。
- 图片和 App 图标预热改为延迟任务，避免搜索输入时同步触发文件读取和缓存预热。
- 关闭历史窗口时取消未完成的搜索和预热任务，避免后台任务在窗口关闭后回写状态。
- 修复搜索框展开但未聚焦时的 Esc 顺序：先清空搜索内容并关闭搜索框，再由下一次 Esc 关闭主窗口。
