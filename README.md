# 轻贴 ClipEase

轻贴 ClipEase 是一款 macOS 菜单栏剪贴板历史工具。它会在本机保存你复制过的内容，让文字、链接、图片、文件和富文本可以随时被搜索、预览、复制或再次粘贴。

## 适合什么场景

- 找回刚刚复制过的文字、链接、图片或文件。
- 用搜索、分组和置顶整理常用内容。
- 在粘贴前先预览图片、链接、文件或富文本。
- 临时暂停记录，或忽略特定 App 的剪贴板内容。

## 安装

前往 [Releases](https://github.com/wengbaby/ClipEase/releases) 下载最新 DMG，打开后将 ClipEase 拖入“应用程序”文件夹。

首次使用时可直接从菜单栏打开轻贴。若希望按回车后自动把内容粘贴回其他 App，请在轻贴的“设置 → 权限”中授予辅助功能权限；未授权时，轻贴仍可正常记录、搜索、预览和复制内容。

## 核心功能

- **多类型历史**：记录文字、链接、颜色、图片、富文本和文件。
- **快速查找**：直接输入关键词，结合分组和来源 App 缩小范围。
- **卡片操作**：复制、粘贴、纯文本粘贴、置顶、删除、加入分组和更多右键操作。
- **丰富预览**：预览文字、图片、链接和文件；预览可拖动为独立窗口。
- **分组整理**：自定义分组名称、图标和颜色，常用内容也可单独置顶。
- **外观自定义**：浅色、深色、跟随系统；窗口效果、卡片样式、透明度、字体与液态玻璃效果均可调整。
- **数据管理**：本地 SQLite 存储，支持保存期限、导入、导出、备份、恢复与清理。
- **记录控制**：可暂停记录、设置开机启动、配置全局快捷键，并忽略指定 App。

## 快速上手

1. 在任意 App 中复制内容，轻贴会将其加入历史。
2. 点击菜单栏中的轻贴图标，打开历史窗口。
3. 单击卡片或使用方向键选中内容。
4. 按回车再次粘贴，或按空格先预览后操作。

## 常用操作与快捷键

| 操作 | 快捷键 |
| --- | --- |
| 预览选中的卡片 | `Space` |
| 粘贴选中内容 | `Return` |
| 粘贴为纯文本 | `Shift + Return` |
| 复制 / 复制纯文本 | `⌘C` / `⇧⌘C` |
| 置顶或取消置顶 | `⌘P` |
| 删除选中卡片 | `Delete` |
| 切换卡片 | `←` / `→` |
| 选择可见区域第 1 至 9 张卡片 | `⌘1` 至 `⌘9` |
| 打开设置 | `⌘,` |
| 编辑当前内容 | `⌘E` |
| 暂停 / 恢复记录 | `⌘T` |
| 关闭预览 | `Esc`；独立预览也支持 `⌘W` |

更多快捷键和说明可在应用内“帮助”查看；全局快捷键可在设置中自行配置。

## 隐私与数据

- 剪贴板历史默认保存在本机，不依赖云端账户。
- 暂停记录不会删除已有历史，只会停止记录之后的新内容。
- 可将特定 App 加入忽略列表，避免记录其剪贴板内容。
- 普通历史会按设置的保存期限清理；置顶内容不会因期限自动删除。
- 执行导入、导出、备份、恢复或清空前，请留意应用内的确认提示。

## 系统要求

- macOS 13.0 或更高版本。
- 仅从源码构建时需要 Swift 6.1 或更高版本。

## 从源码构建

```bash
# 构建发布版可执行文件
swift build -c release --product ClipEase

# 构建 macOS App
scripts/build-app.sh --bump none

# 构建并启动 App
scripts/build-app.sh --bump none --run
```

构建产物位于 `.build/ClipEase.app`。测试可通过以下命令运行：

```bash
swift test
```

## 项目结构

```text
.
├── Resources/       # 应用图标、信息配置、音效与资源
├── Sources/ClipEase/
│   ├── App/         # 应用入口、菜单栏与生命周期
│   ├── Core/        # 数据模型、设置、SQLite 存储与通用服务
│   └── Features/    # 剪贴板监听、历史窗口、预览、设置、帮助与粘贴
├── Tests/           # 单元与集成测试
├── images/          # README 展示图片
└── scripts/         # 构建、版本和发布脚本
```
