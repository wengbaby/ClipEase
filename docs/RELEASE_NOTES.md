# 第二版发布说明

## 版本定位

轻贴 ClipEase 第二版是本地优先的 macOS 菜单栏剪贴板历史工具，重点是快速记录、稳定检索、统一预览、文件卡片和流畅操作体验。

当前发布候选包：`2.3.2 (260523.0437)`。

## 系统要求

- macOS 13 Ventura 或更高版本。
- 建议开启辅助功能权限，用于全局快捷键、回到原 App 粘贴和部分窗口交互。
- 数据默认保存在当前用户的 Application Support 目录。
- 第二版不包含 iCloud 同步。未加入付费 Apple Developer Program 时，可继续本地使用和通过 DMG 分享，但系统可能要求右键打开、手动信任和重新授权隐私权限。

## 第二版功能

- 菜单栏常驻，不显示 Dock 图标。
- 底部横向历史窗口，支持横向滚动、边缘卡片点击滚动和最新卡片自动定位。
- 支持文本、富文本、链接、图片、颜色和文件卡片。
- SQLite-only 本地存储，历史索引和附件分开保存。
- 搜索、分组、置顶、删除、清空历史和保存期限设置。
- 单击选中、双击粘贴、回车粘贴、`Command + 1-9` 快速粘贴当前可见卡片。
- 卡片拖拽到其他 App 时使用整张卡片快照浮层，文本、链接、颜色、图片和文件保持统一拖拽体验。
- 复制和粘贴成功时播放项目内置音效。
- 预览窗口支持文本、图片、PDF、链接、颜色和文件；预览可从标题栏拖出成为独立窗口。
- 图片和 PDF 支持后台 OCR / Live Text 能力，识别结果、邮箱、电话、网址等关键信息按系统能力展示。
- 文件卡片支持复制文件引用、路径 fallback、拖出到其他 App、在 Finder 中显示，以及系统 Quick Look 预览。
- 历史导入导出、备份包导入导出、数据健康检查和孤立附件清理。

## 权限说明

轻贴可以在无辅助功能权限时记录和复制内容，但自动粘贴、全局键盘路由和回到原 App 光标位置粘贴需要 macOS 辅助功能权限。

如果已授权但仍提示缺少权限，请确认系统设置中授权的 App 路径与当前运行的 `.app` 路径一致。

## 文件预览说明

- 图片和 PDF 尽量提供可选择文字、复制文字和 OCR 高亮能力，实际识别质量取决于原图清晰度和 macOS Vision / Live Text 能力。
- Office 文件通过系统 Quick Look 保留原本格式。Quick Look 不能稳定提供正文级文本选择时，轻贴不会额外伪造一个破坏格式的文本区域。
- 不支持预览的文件会显示文件图标、名称和路径，用户仍可复制路径或在 Finder 中显示。

## 发布前验证

App 代码发生变化时，必须先按版本规则构建并运行新版本：

```bash
./scripts/build-app.sh --bump patch --run   # 修复 bug / polish
./scripts/build-app.sh --bump minor --run   # 新增功能
```

当前 `.app` 已构建并运行后，再执行最终发布门禁：

```bash
python3 scripts/final_release_gate.py
```

生成 DMG 时使用：

```bash
./scripts/build-dmg.sh
```

`final_release_gate.py` 不重新编译 App，只检查当前 `.build/ClipEase.app`、版本一致性、发布文档和已沉淀的静态 / 性能守卫，避免发布前不小心绕过版本递增和运行规则。

## 数据安全

- 历史数据使用本地 SQLite 保存。
- 图片、富文本、文件预览相关附件保存在 Application Support 目录。
- 备份导入采用非破坏性合并，不覆盖现有历史。
- 文件卡片优先保存文件引用和路径信息，不主动修改、移动或删除原文件。
