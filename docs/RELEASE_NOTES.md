# 第一版发布说明

## 版本定位

轻贴 ClipEase 第一版是本地优先的 macOS 菜单栏剪贴板历史工具，重点是稳定记录、快速查找、预览和再次粘贴。

## 系统要求

- macOS 13 Ventura 或更高版本
- 建议开启辅助功能权限，用于全局快捷键监听和自动粘贴
- 数据默认保存在当前用户的 Application Support 目录

## 第一版功能

- 菜单栏常驻，不显示 Dock 图标
- 底部横向历史窗口，支持鼠标滚轮和触控板横向浏览
- 记录文本、图片、链接、颜色和新建富文本
- 搜索、筛选、置顶、删除、清空历史
- 单击选中、双击粘贴、回车粘贴
- `Command + 1-9` 快速粘贴当前可见卡片
- 空格预览文本、图片、链接和颜色
- 链接预览内嵌网页，图片预览按比例适配窗口
- 暂停和恢复记录，支持定时暂停
- 保存期限：1 天、3 天、5 天、7 天、30 天、永久
- 忽略指定 App
- 开机自动启动
- 历史导入导出、备份包导入导出
- 存储用量、数据健康检查、孤立附件清理

## 权限说明

轻贴可以在无辅助功能权限时记录和复制内容，但自动粘贴、全局键盘路由等体验需要 macOS 辅助功能权限。

如果已授权但仍提示缺少权限，请确认系统设置中授权的 App 路径与当前运行的 `.app` 路径一致。

## 发布前验证

每次发布候选包必须执行：

```bash
swift build
scripts/smoke_check.py
scripts/build-app.sh --run
```

随后按 [第一版回归测试清单](./FIRST_VERSION_TEST_CHECKLIST.md) 进行手动验收。

进入第一版 RC 后，阻塞修复使用 patch 版本递增，例如 `1.0.1 -> 1.0.2`。任何一次打包都会更新时间戳构建号。

## 数据安全

- 历史索引使用本地 JSON 文件保存。
- 图片、缩略图、App 图标和富文本附件保存在 Application Support 目录。
- 历史文件损坏时，轻贴会先备份损坏文件，再以空历史安全启动。
- 导入历史采用追加合并，不覆盖现有历史。

## 升级到第一版

从 `0.x.x` 首次进入第一版时，使用大版本规则构建 `1.0.0` 候选包：

```bash
scripts/build-app.sh --bump major --run
```

如果已经是 `1.0.x` 修复轮，则使用 patch 规则构建新的候选包：

```bash
scripts/build-app.sh --bump patch --run
```
