# 开发日志规范

每日开发日志放在 `dev-logs/YYYY-MM-DD.md`。

## 目的

- 记录每天完成了什么。
- 记录当天验证了什么。
- 记录未完成事项。
- 记录风险和决策，避免项目失控。

## 日志格式

每个日志文件包含：

- 日期
- 今日目标
- 已完成
- 验证结果
- 遇到的问题
- 明日待办
- 决策记录

## 自动创建

脚本路径：

- `scripts/daily_log.py`

运行方式：

```bash
python3 scripts/daily_log.py
```

该脚本会创建或补全当天日志文件。它不会替开发者判断实际完成内容，开发者仍需要根据当天工作填写具体事项。

## 记录要求

- 完成事项要具体，不写空话。
- 验证结果必须说明做了什么验证。
- 待办事项只写下一步真正要做的内容。
- 遇到风险要及时记录。
