## 分类说明

- `ai/` — AI 协作过程文档（bug 修复、需求实现、计划执行、重构记录）
- `releases/` — 发版相关（原作者保留，单独 git 追踪规则）

## 如何新增文档

1. 在 `docs/ai/`（或新建子目录）下创建 `YYYY-MM-DD-HHmmss-简短中文概括.md`。
2. 文档内容至少含：文档日期、状态、约束对齐、关联记叙、目标；开发文档还要写问题现象/根因/改动点/验证/影响范围。
3. 在本索引表格里追加一行。
4. 提交 git 时把文档和代码改动一起提交。
