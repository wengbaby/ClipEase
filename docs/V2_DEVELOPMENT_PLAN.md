# 第二版开发计划草案

## 1. 推进原则

第二版继续小步推进，每轮最多实现少量同类功能。

原则：

- 先方案，后代码。
- 先数据安全，后界面增强。
- 先迁移和备份，后替换主存储。
- 收藏、分组、搜索都必须建立在稳定数据层之上。
- iCloud 同步先预研，不进入第二版第一阶段实现。
- 第二版已确认的产品规则必须先写入方案，再进入实现。

## 2. 阶段 0：第二版方案确认

目标：

- 确认第二版产品范围。
- 确认 SQLite、收藏、分组、更强搜索的优先级。
- 确认暂缓项。
- 确认快捷键体系、全局提示层、富文本卡片展示、窗口层级等细节。

完成标准：

- `docs/V2_PRODUCT_PLAN.md` 经用户确认。
- `docs/V2_TECHNICAL_PLAN.md` 经用户确认。
- `docs/V2_DEVELOPMENT_PLAN.md` 经用户确认。

## 3. 阶段 1：SQLite 基础和迁移验证

目标：

- 建立 SQLite 存储层。
- 设计表结构。
- 从现有 JSON 做只读迁移验证。

完成标准：

- 不影响第一版现有 JSON 数据。
- 可以把 JSON 历史导入 SQLite 测试库。
- 迁移失败不会影响 App 启动。
- 有迁移日志和错误统计。

## 4. 阶段 2：Repository 抽象

目标：

- 把 UI 和存储细节隔离。
- 为 JSON 到 SQLite 切换做准备。

完成标准：

- 历史查询、添加、删除、置顶、清理都通过统一接口。
- 旧 JSON 实现仍可工作。
- SQLite 实现可以在开发开关下验证。

## 5. 阶段 3：SQLite 成为主存储

目标：

- 将 SQLite 切换为主存储。
- JSON 作为迁移来源和安全备份。

完成标准：

- App 正常记录、搜索、预览、粘贴。
- 历史重启后保留。
- 导入导出逻辑适配 SQLite。
- 数据健康检查支持 SQLite。

## 6. 阶段 4：收藏 / 永久保存

目标：

- 实现收藏和取消收藏。
- 收藏独立于置顶。
- 收藏内容不被普通保存期限清理。

完成标准：

- 右键菜单可收藏。
- 顶部筛选可查看收藏。
- 收藏内容可取消收藏。
- 清理普通历史不会误删收藏附件。
- 取消收藏后，内容回到普通历史并按当前保存期限清理。

## 7. 阶段 5：分组基础

目标：

- 实现单层分组。
- 收藏内容可加入分组。
- 主窗口顶部展示 Pinboard 风格分组按钮。

完成标准：

- 可创建、重命名、删除分组。
- 可修改分组颜色。
- 可选择分组图标，或使用颜色 + 图标组合。
- 分组图标来源为系统图标 + 轻贴内置图标库，暂不支持自定义图片。
- 顶部分组按钮按颜色区分，右侧 `+` 可新建分组。
- 顶部分组栏支持横向滚动。
- 分组顶部按钮默认不显示数量，悬停时显示数量。
- 新建分组默认名称为“新分组”，默认随机颜色，创建后立即允许用户修改名称、颜色和图标。
- 可将收藏内容移动到分组。
- 普通历史执行“收藏到分组”时自动成为收藏内容。
- 空分组删除不需要确认。
- 有内容分组删除时使用普通确认弹窗，显示会删除多少条内容且无法恢复。
- 分组支持拖拽排序。
- 分组筛选可用。

## 8. 阶段 6：更强搜索

目标：

- 搜索支持来源 App、类型、时间范围、收藏、分组组合条件。
- 筛选入口移动到搜索框右侧。
- 搜索框打开后，再按 `Command + F` 弹出筛选面板。
- 搜索框支持多个筛选 token 并存。

完成标准：

- 搜索结果完整。
- 大量历史下输入不卡顿。
- 高亮和筛选状态清晰。
- 搜索不会牺牲数据完整性。
- 筛选面板按类型、来源 App、日期、设备等分类展示。
- 来源 App 按最近使用排序。
- 类型筛选一次只能选一种类型。
- 设备筛选默认不显示，只有未来同步预研相关功能开启后才显示。
- 筛选弹层位置和样式参考 Paste，锚定搜索框右侧筛选按钮。

## 9. 阶段 7：编辑、快捷键和批量管理

目标：

- 普通历史和收藏文本可编辑。
- 文本/链接卡片支持 `Command + E` 编辑。
- 链接卡片编辑时编辑 URL 地址，并提供“在 默认浏览器 中打开”入口。
- 常用菜单命令补齐快捷键。
- 支持多选和批量操作。
- 卡片右键菜单显示已有快捷键，并按类别用分割线分组。

完成标准：

- 普通历史编辑提交后更新原记录内容，不新增记录。
- 原记录如果属于收藏、分组或置顶，编辑后仍保留对应状态。
- 编辑记录不保留编辑前版本历史。
- 右键菜单“编辑”对文本、链接、颜色卡片显示；图片暂不显示编辑入口。
- 收藏文本编辑后可再次粘贴。
- 右键菜单、系统菜单和主窗口更多菜单中的常用命令快捷键一致。
- 主窗口右侧 `...` 菜单和菜单栏图标右键菜单快捷键同步。
- 卡片右键菜单显示预览 `Space`、粘贴 `Return`、粘贴为纯文本 `Shift + Return`、复制 `Command + C`、复制纯文本 `Shift + Command + C`。
- `Command + D` 可收藏 / 取消收藏。
- `Command + M` 可进入或退出管理模式。
- 批量删除、收藏、移动到分组可用。
- 批量操作有确认和撤销策略。

## 10. 阶段 8：主窗口体验细节

目标：

- 有新剪贴板历史时，下次打开主窗口回到第一条卡片。
- 主窗口和预览窗口层级稳定。
- 从主窗口更多菜单打开新建文本时隐藏主窗口。
- 所有短提示迁移到统一全局提示层。
- 主窗口顶部参考 Paste 简化，移除设置页已有状态项的重复展示。
- 主窗口右侧更多按钮只显示 `...`。

完成标准：

- 没有新历史时，主窗口仍能恢复用户上次横向位置。
- 有新历史时，主窗口打开后定位到最新卡片。
- 预览窗口始终在主窗口前方。
- 全局提示层显示来源 App 图标和短提示，位于底部中间靠上一点，不被其他窗口遮挡，约 1 秒自动消失。
- 不在主窗口顶部常驻显示“自动粘贴”“记录中”“永久记录”等设置项。
- 搜索框、筛选按钮、顶部字体和图标尺寸比第一版更易点击。
- 主窗口默认只显示搜索图标，点击搜索图标或直接输入后展开搜索框。

## 11. 阶段 9：内容增强

目标：

- 链接卡片增强。
- 图片操作增强。
- 富文本卡片展示。
- 隐私和敏感内容能力增强。

完成标准：

- 链接标题、图标、描述更稳定。
- 图片可导出、查看原图、复制为文件。
- 富文本卡片能尽量按照复制时的格式显示，同时不影响主窗口流畅度。
- 忽略 App 和敏感遮罩能力清晰可控。
- 敏感遮罩默认关闭，但需要有引导说明如何开启。
- 点击被遮罩内容需要通过系统密码或 Touch ID 验证后显示。

## 12. 阶段 10：iCloud 同步预研

目标：

- 不实现正式同步，只产出技术预研和风险结论。

完成标准：

- 明确是否适合使用 CloudKit。
- 明确附件同步策略。
- 明确冲突解决策略。
- 明确隐私和加密要求。

## 13. 当前待确认

- 链接编辑窗口是否只保存 URL，还是未来也要增加标题/备注字段。
- Touch ID / 系统密码验证通过后，被遮罩内容显示多久。
- 搜索框中多个筛选 token 的删除方式，是点击 token 上的关闭按钮，还是用 Backspace 逐个删除。
- 筛选面板是否需要保存上次打开位置和滚动位置。
- 颜色卡片编辑时，是编辑 HEX 值还是打开颜色选择器。
- 搜索框展开后是否自动聚焦并选中当前搜索词。
