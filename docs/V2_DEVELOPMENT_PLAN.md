# 第二版开发计划草案

## 1. 推进原则

第二版继续小步推进，每轮最多实现少量同类功能。

原则：

- 先方案，后代码。
- 先数据安全，后界面增强。
- 先迁移和备份，后替换主存储。
- 收藏、分组、搜索都必须建立在稳定数据层之上。
- iCloud 同步先预研，不进入第二版第一阶段实现。
- 第二版已确认的产品规则必须先写入方案，再进入实现。

## 2. 阶段 0：第二版方案确认

目标：

- 确认第二版产品范围。
- 确认 SQLite、收藏、分组、更强搜索的优先级。
- 确认暂缓项。
- 确认快捷键体系、全局提示层、富文本卡片展示、窗口层级等细节。

完成标准：

- `docs/V2_PRODUCT_PLAN.md` 经用户确认。
- `docs/V2_TECHNICAL_PLAN.md` 经用户确认。
- `docs/V2_DEVELOPMENT_PLAN.md` 经用户确认。

## 3. 阶段 1：SQLite 基础和迁移验证

目标：

- 建立 SQLite 存储层。
- 设计表结构。
- 从现有 JSON 做只读迁移验证。

完成标准：

- 不影响第一版现有 JSON 数据。
- 可以把 JSON 历史导入 SQLite 测试库。
- 迁移失败不会影响 App 启动。
- 有迁移日志和错误统计。

## 4. 阶段 2：Repository 抽象

目标：

- 把 UI 和存储细节隔离。
- 为 JSON 到 SQLite 切换做准备。

完成标准：

- 历史查询、添加、删除、置顶、清理都通过统一接口。
- 旧 JSON 实现仍可工作。
- SQLite 实现可以在开发开关下验证。

## 5. 阶段 3：SQLite 成为主存储

目标：

- 将 SQLite 切换为主存储。
- JSON 作为迁移来源和安全备份。

完成标准：

- App 正常记录、搜索、预览、粘贴。
- 历史重启后保留。
- 导入导出逻辑适配 SQLite。
- 数据健康检查支持 SQLite。

## 6. 阶段 4：收藏 / 永久保存

目标：

- 实现收藏和取消收藏。
- 收藏独立于置顶。
- 收藏内容不被普通保存期限清理。

完成标准：

- 右键菜单可收藏。
- 顶部筛选可查看收藏。
- 收藏内容可取消收藏。
- 清理普通历史不会误删收藏附件。
- 取消收藏后，内容回到普通历史并按当前保存期限清理。

## 7. 阶段 5：分组基础

目标：

- 实现单层分组。
- 收藏内容可加入分组。

完成标准：

- 可创建、重命名、删除分组。
- 可将收藏内容移动到分组。
- 普通历史执行“收藏到分组”时自动成为收藏内容。
- 删除分组时可选择移动到未分组或删除内容。
- 分组筛选可用。

## 8. 阶段 6：更强搜索

目标：

- 搜索支持来源 App、类型、时间范围、收藏、分组组合条件。

完成标准：

- 搜索结果完整。
- 大量历史下输入不卡顿。
- 高亮和筛选状态清晰。
- 搜索不会牺牲数据完整性。

## 9. 阶段 7：编辑、快捷键和批量管理

目标：

- 普通历史和收藏文本可编辑。
- 文本/链接卡片支持 `Command + E` 编辑。
- 常用菜单命令补齐快捷键。
- 支持多选和批量操作。

完成标准：

- 普通历史编辑提交后生成新的历史文本记录，不覆盖原始记录。
- 收藏文本编辑后可再次粘贴。
- 右键菜单、系统菜单和主窗口更多菜单中的常用命令快捷键一致。
- 批量删除、收藏、移动到分组可用。
- 批量操作有确认和撤销策略。

## 10. 阶段 8：主窗口体验细节

目标：

- 有新剪贴板历史时，下次打开主窗口回到第一条卡片。
- 主窗口和预览窗口层级稳定。
- 从主窗口更多菜单打开新建文本时隐藏主窗口。
- 所有短提示迁移到统一全局提示层。

完成标准：

- 没有新历史时，主窗口仍能恢复用户上次横向位置。
- 有新历史时，主窗口打开后定位到最新卡片。
- 预览窗口始终在主窗口前方。
- 全局提示层显示在底部中间靠上一点，不被其他窗口遮挡，约 1 秒自动消失。

## 11. 阶段 9：内容增强

目标：

- 链接卡片增强。
- 图片操作增强。
- 富文本卡片展示。
- 隐私和敏感内容能力增强。

完成标准：

- 链接标题、图标、描述更稳定。
- 图片可导出、查看原图、复制为文件。
- 富文本卡片能显示基础格式，同时不影响主窗口流畅度。
- 忽略 App 和敏感遮罩能力清晰可控。

## 12. 阶段 10：iCloud 同步预研

目标：

- 不实现正式同步，只产出技术预研和风险结论。

完成标准：

- 明确是否适合使用 CloudKit。
- 明确附件同步策略。
- 明确冲突解决策略。
- 明确隐私和加密要求。

## 13. 当前待确认

- `Command + E` 编辑链接卡片时，是编辑链接标题/备注，还是编辑链接本身。
- 收藏 / 取消收藏是否需要快捷键，建议候选为 `Command + D`。
- 管理模式快捷键是否使用 `Command + M`，或只通过菜单进入。
- 全局提示层是否显示来源图标，还是只显示操作图标和文字。
- 富文本卡片是否显示文字颜色和背景色，还是只显示粗体、斜体、下划线、删除线和字号。
