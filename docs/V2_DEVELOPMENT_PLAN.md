# 第二版开发计划草案

## 1. 推进原则

第二版继续小步推进，每轮最多实现少量同类功能。

原则：

- 先方案，后代码。
- 先数据安全，后界面增强。
- 先迁移和备份，后替换主存储。
- 收藏、分组、搜索都必须建立在稳定数据层之上。
- iCloud 同步先预研，不进入第二版第一阶段实现。
- 第二版已确认的产品规则必须先写入方案，再进入实现。

## 2. 阶段 0：第二版方案确认

目标：

- 确认第二版产品范围。
- 确认 SQLite、收藏、分组、更强搜索的优先级。
- 确认暂缓项。
- 确认快捷键体系、全局提示层、富文本卡片展示、窗口层级等细节。

完成标准：

- `docs/V2_PRODUCT_PLAN.md` 经用户确认。
- `docs/V2_TECHNICAL_PLAN.md` 经用户确认。
- `docs/V2_DEVELOPMENT_PLAN.md` 经用户确认。
- 创建第二版测试计划文档，覆盖 SQLite 迁移、搜索筛选、收藏分组、备份导入导出、敏感遮罩、文件卡片和 Quick Look 预览。

## 3. 阶段 1：SQLite 基础和迁移验证

目标：

- 建立 SQLite 存储层。
- 设计表结构。
- 直接切换 App 主存储进行 SQLite 迁移验证。

完成标准：

- 从现有 `history.json` 导入 SQLite。
- 可以把 JSON 历史导入 SQLite 测试库。
- 数据库文件名为 `ClipEase.sqlite`。
- 迁移前不额外备份 JSON。
- 迁移失败后清空数据重建。
- 迁移失败清空重建前不做二次确认，直接重建。
- 迁移成功后删除原 JSON。
- 有迁移日志和错误统计。
- 迁移过程显示进度。
- 设置页保留最近 5 次迁移结果。
- 第二版第一阶段从 SQLite 迁移验证开始。

## 4. 阶段 2：Repository 抽象

目标：

- 把 UI 和存储细节隔离。
- 为 JSON 到 SQLite 切换做准备。

完成标准：

- 历史查询、添加、删除、置顶、清理都通过统一接口。
- 旧 JSON 实现仍可工作。
- SQLite 实现可以在开发开关下验证。

## 5. 阶段 3：SQLite 成为主存储

目标：

- 将 SQLite 切换为主存储。
- JSON 只作为迁移来源；迁移成功后按已确认规则删除原 JSON。

完成标准：

- App 正常记录、搜索、预览、粘贴。
- 历史重启后保留。
- 导入导出逻辑适配 SQLite，默认使用 SQLite 备份包，扩展名为 `.clipeasebackup`。
- 导出备份包时由用户选择是否包含图片、富文本等附件。
- 导出备份包时，“包含附件”默认勾选。
- 导出备份成功后显示提示，用户点击“显示”后再在 Finder 中定位文件。
- 导入备份包遇到重复记录时弹窗让用户选择处理方式。
- 导入备份包遇到重复记录时，弹窗默认推荐“跳过重复”。
- 数据健康检查优先支持 SQLite，发现问题后提供“一键修复”。
- 数据健康检查“一键修复”前每次都确认，完成后生成简短报告。
- 1,000 / 10,000 条测试数据入口移到设置页隐藏入口，通过连点版本号 5 次显示。

## 6. 阶段 4：收藏 / 永久保存

目标：

- 实现收藏和取消收藏。
- 收藏独立于置顶。
- 收藏内容不被普通保存期限清理。

完成标准：

- 右键菜单可收藏。
- 预览窗口工具栏可收藏。
- 顶部筛选可查看收藏。
- 收藏内容可取消收藏。
- 收藏卡片显示星标。
- 置顶和收藏同时存在时，同时显示图钉和星标。
- 收藏筛选中，置顶内容在前，其余按收藏时间倒序。
- 清理普通历史不会误删收藏附件。
- 取消收藏后，内容回到普通历史并按当前保存期限清理。
- 如果取消收藏时内容仍属于分组，则保留分组归属。
- 取消收藏但内容仍属于分组时，分组内继续显示该内容，并用空心星标标记为非收藏。

## 7. 阶段 5：分组基础

目标：

- 实现单层分组。
- 收藏内容可加入分组。
- 主窗口顶部展示 Pinboard 风格分组按钮。

完成标准：

- 可创建、重命名、删除分组。
- 可修改分组颜色。
- 可选择分组图标，或使用颜色 + 图标组合。
- 分组图标来源为系统图标 + 轻贴内置图标库，暂不支持自定义图片。
- 分组颜色允许使用系统取色器自定义。
- 分组图标允许搜索。
- 顶部分组按钮按颜色区分，右侧 `+` 可新建分组。
- 顶部分组栏支持横向滚动，并在右侧提供更多分组入口。
- 分组顶部按钮默认不显示数量，悬停时显示数量。
- 分组里的内容按加入分组时间倒序排列。
- 新建分组默认名称为“新分组”，默认颜色来自固定预设色板，默认图标为随机图标，创建后立即允许用户修改名称、颜色和图标。
- 新建分组后不自动进入新分组，主窗口仍停留在当前分组。
- 分组重命名支持右键分组按钮和双击分组按钮。
- 分组颜色和图标修改支持右键分组按钮和分组管理面板。
- 有内容分组删除确认弹窗的危险按钮文案为“删除分组和内容”。
- 更多分组入口点击右侧“更多”按钮弹出菜单。
- 更多分组超过 10 个时显示分组搜索。
- 分组管理窗口允许批量删除分组。
- 可将收藏内容移动到分组。
- 普通历史执行“收藏到分组”时自动成为收藏内容。
- 普通历史“收藏到分组”后，原记录变成收藏并进入分组，不复制新记录。
- 空分组删除不需要确认。
- 有内容分组删除时使用普通确认弹窗，显示会删除多少条内容且无法恢复。
- 分组支持拖拽排序。
- 分组筛选可用。

## 8. 阶段 6：更强搜索

目标：

- 搜索支持来源 App、类型、时间范围、收藏、分组组合条件。
- 搜索方案同时准备普通索引 + `LIKE` 和 FTS5。
- 筛选入口移动到搜索框右侧。
- 搜索框未展开时，按 `Command + F` 展开搜索框并聚焦。
- 搜索框打开后，再按 `Command + F` 弹出筛选面板。
- 筛选面板打开时，再按 `Command + F` 关闭筛选面板并聚焦搜索框。
- 搜索框支持多个筛选 token 并存。
- SQLite 基础完成后，优先推进搜索 / 筛选重构。

完成标准：

- 搜索结果完整。
- 大量历史下输入不卡顿。
- 高亮和筛选状态清晰。
- 搜索不会牺牲数据完整性。
- 默认搜索路径根据实际性能动态决定。
- 筛选面板按类型、来源 App、日期、设备等分类展示。
- 来源 App 按最近使用排序。
- 类型筛选一次只能选一种类型。
- 筛选 token 可通过关闭按钮或 Backspace 删除。
- 多个筛选 token 在搜索框内横向展示，超出宽度时横向滚动。
- 搜索框横向滚动时，输入光标必须保持可见。
- 筛选 token 不支持拖拽排序，按固定顺序展示：类型、App、日期、分组。
- 固定顺序中如果没有某一类筛选条件，后续 token 前移，保持紧凑。
- 筛选 token 点击本体无动作，只能通过关闭按钮、Backspace 或筛选面板修改。
- 筛选面板不长期记住上次打开位置和滚动位置。
- 筛选面板每次打开回到顶部。
- 筛选面板顶部不显示已选条件摘要。
- 设备筛选默认不显示，只有未来同步预研相关功能开启后才显示。
- 筛选弹层位置和样式参考 Paste，锚定搜索框右侧筛选按钮。

## 9. 阶段 7：编辑、快捷键和批量管理

目标：

- 普通历史和收藏文本可编辑。
- 文本/链接卡片支持 `Command + E` 编辑。
- 链接卡片编辑时编辑 URL 地址，并提供“在 默认浏览器 中打开”入口。
- 常用菜单命令补齐快捷键。
- 支持多选和批量操作。
- 卡片右键菜单显示已有快捷键，并按类别用分割线分组。

完成标准：

- 普通历史编辑提交后更新原记录内容，不新增记录。
- 原记录如果属于收藏、分组或置顶，编辑后仍保留对应状态。
- 编辑记录不保留编辑前版本历史。
- 右键菜单“编辑”对文本、链接、颜色卡片显示；图片暂不显示编辑入口。
- 颜色卡片编辑同时支持输入 HEX 和使用系统颜色选择器。
- 颜色卡片编辑保存后只更新历史记录，不立即复制新颜色到剪贴板。
- 颜色卡片编辑保存后只刷新颜色预览区域，不刷新卡片顶部标题栏颜色。
- 颜色卡片编辑保存后显示全局提示“颜色已更新”。
- 链接 URL 编辑保存后，后台重新抓取网页标题和图标。
- 链接 URL 编辑保存后，立即复制新 URL 到剪贴板。
- 链接 URL 编辑保存后显示全局提示“链接已更新并复制”。
- 链接编辑窗口只编辑 URL，不增加标题和备注字段。
- 卡片右键菜单快捷键使用 macOS 符号格式，例如 `⌘C`、`⇧⌘C`、`⏎`。
- 收藏文本编辑后可再次粘贴。
- 右键菜单、系统菜单和主窗口更多菜单中的常用命令快捷键一致。
- 主窗口右侧 `...` 菜单和菜单栏图标右键菜单快捷键同步。
- 卡片右键菜单显示预览 `Space`、粘贴 `Return`、粘贴为纯文本 `Shift + Return`、复制 `Command + C`、复制纯文本 `Shift + Command + C`。
- `Command + D` 可收藏 / 取消收藏。
- `Command + M` 可进入或退出管理模式。
- 批量删除、收藏、移动到分组可用。
- 批量操作有确认和撤销策略。

## 10. 阶段 8：主窗口体验细节

目标：

- 有新剪贴板历史时，下次打开主窗口回到第一条卡片。
- 主窗口和预览窗口层级稳定。
- 从主窗口更多菜单打开新建文本时隐藏主窗口。
- 从主窗口更多菜单新建文本时，内容默认归属当前选中的分组；如果当前在“全部剪切板”分组，则进入普通历史。
- 新建文本窗口允许选择分组。
- 新建文本创建成功后，打开主窗口，并显示和选中新记录。
- 所有短提示迁移到统一全局提示层。
- 主窗口顶部参考 Paste 简化，移除设置页已有状态项的重复展示。
- 主窗口右侧更多按钮只显示 `...`。

完成标准：

- 没有新历史时，主窗口仍能恢复用户上次横向位置。
- 有新历史时，主窗口打开后定位到最新卡片。
- 预览窗口始终在主窗口前方。
- 全局提示层始终显示来源 App 图标和短提示，位于底部中间靠上一点，不被其他窗口遮挡，约 1 秒自动消失。
- 不在主窗口顶部常驻显示“自动粘贴”“记录中”“永久记录”等设置项。
- 搜索框、筛选按钮、顶部字体和图标尺寸比第一版更易点击。
- 主窗口默认只显示搜索图标，点击搜索图标或直接输入后展开搜索框。
- 搜索框展开后自动聚焦，光标停在末尾，不选中已有内容。
- 搜索框中筛选 token 在前，关键词在后。
- 点击搜索框清空按钮时，同时清空关键词和全部筛选 token。
- 搜索框清空按钮在有关键词或筛选 token 时显示。
- 点击清空按钮后保持搜索框展开并聚焦；按 Esc 仍按分层关闭规则执行。
- Esc 处理顺序为：关闭筛选面板、清空搜索内容和筛选 token、关闭搜索框、关闭主窗口。
- 搜索框展开后，点击主窗口内其他区域时搜索框保持展开。
- 筛选面板打开时，点击主窗口卡片先关闭筛选面板，再选中卡片。
- 搜索框展开且没有关键词和筛选 token 时，点击主窗口外部直接关闭主窗口。
- 筛选面板打开时，点击主窗口外部同时关闭筛选面板和主窗口。
- 搜索框聚焦时，左右方向键优先移动文本光标。
- 搜索框聚焦时，上下方向键按系统文本框默认行为处理。
- 搜索框聚焦时，按回车进入卡片选择。
- 搜索框光标位于文本末尾时，按方向右键或方向下键进入卡片选择。
- 进入卡片选择后，搜索框保持展开，卡片显示选中态。
- 从卡片选择返回搜索框的方式为点击搜索框或按 `Command + F`。
- 搜索框聚焦时按 Tab 进入卡片列表；卡片列表中再次按 Tab 返回搜索框，光标回到原位置。
- 卡片列表中按 `Shift + Tab` 反向切换卡片。
- 搜索框有中文输入法候选时，回车优先确认候选词；没有候选框时，回车进入卡片选择。
- 卡片选择状态下继续输入文字，会回到搜索框并追加输入。
- 卡片选择状态下继续输入文字后，保留当前卡片选中态，直到搜索结果更新。
- 搜索结果更新后，自动选中第一条结果。
- 卡片选择状态下按 Delete 或 Backspace 删除选中卡片。
- Delete / Backspace 删除卡片不弹确认，直接删除。
- 删除当前卡片后选中右侧下一张。
- 删除卡片后显示全局提示“已删除 撤销”，持续 8 秒。
- 撤销后卡片恢复到原位置。
- 批量删除支持逐条撤销，撤销过程需要有动画。
- 批量删除逐条撤销时，按删除前位置从左到右恢复。
- 删除收藏或分组里的内容时，从所有地方彻底删除。
- 删除图片卡片时立即删除本地图片附件。
- 撤销图片删除时需要恢复已删除的本地图片附件。
- 点击清空按钮后不显示全局提示。

## 11. 阶段 9：内容增强

目标：

- 链接卡片增强。
- 图片和文件操作增强。
- 文件卡片和系统级预览。
- 富文本卡片展示。
- 隐私和敏感内容能力增强。

完成标准：

- 链接标题、图标、描述更稳定。
- 图片可导出、查看原图、复制为文件。
- 复制 1 个本地文件时，记录文件本地路径。
- 文件卡片标题显示“1 个文件”，内容显示系统文件图标或缩略图，底部显示本地路径。
- 文件预览窗口优先使用 macOS Quick Look 能力展示图片、文档、PDF 等系统可预览内容。
- 不支持系统预览的文件显示系统文件图标和基础信息。
- 文件路径失效时不删除历史记录，但卡片和预览需要提示路径失效。
- 富文本卡片能尽量按照复制时的格式显示，同时不影响主窗口流畅度。
- 富文本编辑保存后尽量保留原富文本格式。
- 忽略 App 和敏感遮罩能力清晰可控。
- 敏感遮罩默认关闭，但需要有引导说明如何开启。
- 点击被遮罩内容需要通过系统密码或 Touch ID 验证后显示。
- 敏感遮罩验证通过后，内容显示 30 秒。
- 敏感内容是否记录原内容由用户按规则选择。

## 12. 阶段 10：iCloud 同步预研

目标：

- 不实现正式同步，只产出技术预研和风险结论。

完成标准：

- 明确是否适合使用 CloudKit。
- 明确附件同步策略。
- 明确冲突解决策略。
- 明确隐私和加密要求。
