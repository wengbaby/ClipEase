## 本次优化

- 优化主窗口卡片渲染窗口，降低大量历史记录下打开主窗口和左右移动时的卡顿。
- 优化搜索结果分页补齐逻辑，减少单字符搜索和筛选搜索时的空白卡片区。
- 优化预览窗口跟随逻辑，键盘移动后预览锚点会重新对准当前聚焦卡片。
- 增加 1000 条文本、3000 条混合数据、1000 条富文本/图片/文件混合的性能基准测试。

## 本次修复

- 修复打开主窗口时卡片偶发不显示，需要滚轮或方向键触发后才显示的问题。
- 修复搜索框聚焦时 Backspace、Command+A 等键盘操作错误作用到卡片的问题。
- 修复搜索后通过 Tab、方向下键或右键切到第一张卡片，再按空格无法打开预览的问题。
- 修复搜索正文部分匹配不稳定的问题，例如正文 `8899` 可通过 `88` 命中。
- 修复轻贴自身复制、双击粘贴、回车粘贴、粘贴为纯文本时被重新记录的问题。
- 修复预览窗口打开时，键盘左右移动到边缘卡片后倒三角没有对准当前聚焦卡片的问题。
