## 本次优化

- 性能日志迁移到独立诊断数据库，避免继续占用剪贴板历史数据库。
- 诊断日志默认保留 3 天、最多 5 MB，并支持在设置中调整保留天数和容量上限。
- 历史数据库支持空闲页超过阈值后自动压缩，并提供手动压缩入口。
- 历史数据页的目录、缓存、清理按钮改为按窗口宽度自适应换行，避免固定行列导致页面错位。

## 本次修复

- 修复历史数据页在默认设置窗口宽度下部分区域过宽、按钮挤压或换行间距过近的问题。
- 修复历史数据摘要只显示分类条数、不显示各分类占用大小的问题。
- 修复性能日志和旧日志文件残留导致历史数据占用显示偏大的问题。
