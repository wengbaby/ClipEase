## 本次优化

- 优化主窗口搜索、焦点切换和卡片渲染链路，提升大数据量历史记录下的流畅度。
- 优化剪贴板写入链路，减少轻贴自身复制/粘贴动作被记录成新卡片的风险。
- 优化性能日志和数据库维护逻辑，性能日志继续使用独立数据库，避免影响历史记录库。
- 增加大数据性能基准，覆盖 1000 条文本、3000 条混合数据、富文本/图片/文件数据和 SQLite 搜索。
- 加固发布脚本，发布前检查远端 main、版本提交状态和 tag 发布流程。

## 本次修复

- 修复搜索框焦点回到输入框后，空格/Backspace 仍可能触发卡片预览或删除的问题。
- 修复搜索后通过 Tab、方向键切到第一张卡片时，空格不能打开预览的问题。
- 修复虚拟渲染下卡片测量帧失效时，预览窗口倒三角可能没有对齐当前卡片的问题。
- 修复重启或新增分组后，第一次打开分组“颜色与图标”弹窗位置不正确的问题。
- 修复部分 Swift 并发警告来源，降低 OCR/PDF 预览相关的非 Sendable 风险。
- 修复数据库空闲页压缩调度过于分散的问题，保留自动检查节流，避免频繁压缩影响使用。
