## 这版改了什么

- 修复历史主窗口高度和间距回归，窗口保持 360 高度，避免顶部空间变高、底部空间消失或卡片贴边。
- 修复快捷键关闭历史主窗口后背景残留的问题；关闭后窗口会真正退出屏幕，不再需要连续按多次 Esc。
- 调整历史主窗口关闭动画，背景和内容会作为同一个窗口一起向下移动，不再出现内容先滑走、背景随后消失的割裂感。
- 优化历史主窗口打开过程，延后预览、搜索、焦点恢复等启动工作，降低打开时掉帧和卡顿。
- 修复搜索框聚焦时的键盘路由：按住 Command 不再显示卡片 1-9 快捷键，Command 组合键继续交给搜索框文本编辑。
- 修复搜索框里按 Enter 或 Tab 跳到第一个历史卡片后，再按 Enter 不能粘贴的问题。
- 优化历史记录去重：不同来源 App 复制到相同内容时会覆盖旧卡片，保留原来的置顶和分组状态，并显示最新来源信息。
- 增加历史窗口生命周期诊断，方便后续定位打开、首帧、预览准备、关闭动画和清理阶段的性能问题。
- 拆分历史窗口内部状态和 AppKit 桥接代码，补充对应回归测试，减少后续优化时影响 UI 布局和交互的风险。
