# 第一版回归测试清单

本清单用于判断轻贴 ClipEase 是否可以从 `0.1.x` 开发版进入 `1.0.0` 第一版。每次准备发布前，按顺序手动验证。

## 1. 启动与窗口

- [ ] 启动 App 后只显示菜单栏图标，不显示 Dock 图标。
- [ ] 点击菜单栏图标可以打开底部历史窗口。
- [ ] `Command + Shift + V` 可以打开或关闭底部历史窗口。
- [ ] 底部窗口从下向上弹出、向下关闭，动画流畅。
- [ ] 点击轻贴窗口外部区域会关闭底部窗口。
- [ ] `Esc` 可以按当前搜索状态正确关闭搜索框或主窗口。

## 2. 剪贴板记录

- [ ] 复制普通文字后，历史窗口出现文本卡片。
- [ ] 复制 URL 后，历史窗口出现链接卡片。
- [ ] 复制颜色值后，历史窗口出现颜色卡片。
- [ ] 复制图片或截图后，历史窗口出现图片卡片。
- [ ] 暂停记录后，新复制内容不会进入历史。
- [ ] 恢复记录后，新复制内容可以继续进入历史。
- [ ] 忽略 App 后，该 App 中复制的内容不会进入历史。

## 3. 卡片操作

- [ ] 单击卡片立即选中，无明显延迟。
- [ ] 左右方向键可以切换选中卡片。
- [ ] 双击卡片可以粘贴到原 App 光标位置。
- [ ] 回车可以粘贴到原 App 光标位置。
- [ ] 按住 `Command` 显示前 9 张卡片序号。
- [ ] `Command + 1-9` 可以直接粘贴对应卡片并关闭窗口。
- [ ] 右键菜单中的复制、粘贴、置顶、删除可用。
- [ ] 置顶卡片始终排在普通历史前面。

## 4. 搜索与筛选

- [ ] 打开轻贴后直接输入文字会自动展开搜索框。
- [ ] 搜索结果完整，不丢数据。
- [ ] 搜索输入过程无明显卡顿。
- [ ] 搜索框内 `Command + A/C/X/V/W` 等原生快捷键可用。
- [ ] 搜索框聚焦时，`Esc` 按清空内容、关闭搜索框、关闭窗口顺序执行。
- [ ] 搜索框未聚焦但展开时，`Esc` 先关闭搜索框，再关闭窗口。
- [ ] 筛选全部、置顶、文字、图片、链接结果正确。

## 5. 预览

- [ ] 空格打开当前卡片预览，再按空格关闭。
- [ ] 预览浮窗悬浮在底部窗口外，不挤压卡片区域。
- [ ] 预览箭头指向当前卡片。
- [ ] 左右切换卡片时，预览内容同步更新。
- [ ] 点击其他卡片或其他窗口后，预览按预期关闭。
- [ ] 大文本预览不会长时间卡住。

## 6. 新建文本

- [ ] 更多菜单可以打开新建文本窗口。
- [ ] 新建文本窗口没有系统红黄绿标题栏。
- [ ] 可以输入中文和英文。
- [ ] 可以选择文本、全选、复制、删除。
- [ ] 加粗、斜体、下划线、删除线和字号调整可用。
- [ ] 点击创建后，新文本进入历史并可再次粘贴。
- [ ] 点击取消后关闭窗口，不创建记录。

## 7. 设置页

- [ ] 打开设置页不会关闭主 App。
- [ ] 设置页红色关闭按钮只关闭设置窗口。
- [ ] 设置页 `Command + W` 只关闭设置窗口。
- [ ] 保存期限切换后生效。
- [ ] 开机启动开关可切换并显示状态。
- [ ] 快捷键修改和恢复默认可用。
- [ ] 暂停 15 分钟、30 分钟、1 小时、3 小时、6 小时、今日结束可用。
- [ ] 辅助功能权限状态刷新准确。

## 8. 数据维护

- [ ] 导出历史成功后，Finder 定位到导出的 JSON 文件。
- [ ] 导入历史成功后，新增记录进入历史。
- [ ] 导出备份包成功后，生成 `.clipeasebackup` 目录。
- [ ] 导入备份包成功后，显示导入、跳过和缺失附件数量。
- [ ] 导入损坏或缺少 `history.json` 的备份包时，有明确错误提示。
- [ ] 刷新用量不会卡住设置页。
- [ ] 检查数据只报告问题，不自动修改文件。
- [ ] 清理孤立附件前有确认弹窗。
- [ ] 清理孤立附件后，存储用量刷新。

## 9. 性能

- [ ] 添加 1,000 条测试文本后，窗口打开和搜索仍流畅。
- [ ] 添加 10,000 条测试文本后，搜索输入没有明显掉帧。
- [ ] 清除测试文本后，真实历史不受影响。
- [ ] 大量图片历史下，缩略图加载不会阻塞窗口动画。

## 10. 发布前

- [ ] `swift build` 通过。
- [ ] `scripts/smoke_check.py` 通过。
- [ ] `scripts/build-app.sh --run` 可构建并启动 App。
- [ ] App 关于页版本号显示正确。
- [ ] Git 工作区干净。
- [ ] GitHub main 分支已推送最新提交。
- [ ] 已知问题记录在 README 或开发日志中。
