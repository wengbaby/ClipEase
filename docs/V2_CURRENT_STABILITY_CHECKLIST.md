# V2 当前稳定性验收清单

当前运行包：`2.3.0 (260523.0333)`

本文用于进入下一批性能 / 动画优化前的人工验收。自动构建已通过；最终发布前人工 UI 验收项已由用户确认通过。

## 文件预览

- Office / 表格类文件在预览框主内容区保留原始格式：`doc`、`docx`、`xls`、`xlsx`、`csv`、`ppt`、`pptx`、`rtf`。
- Office / 表格类文件不再显示为纯文本预览，不再出现底部额外“可复制文本内容”区域。
- 不支持或路径不可用的文件仍显示文件图标、文件名、路径和状态，不退出 App。
- 多文件卡片右侧列表可切换文件，选中项清晰。
- 普通纯文本文件仍可在主内容区选择、复制、右键操作。
- PDF 预览仍可滚动、选择和复制可选文本。
- 图片预览仍按内容区域等比例缩放，不覆盖预览窗口顶部和底部。

## Office 预览边界

- 轻贴当前使用嵌入式 `QLPreviewView` 保留 Office 原格式。
- 嵌入式 Quick Look 的内容选择 / 复制能力由系统实现决定，不能稳定保证等同 Finder 空格预览。
- 不再使用私有 Quick Look 激活接口，因为该路径已确认可能导致 App 崩溃。

## 图片 / OCR

- 图片预览打开后，图片应在内容区域内等比例缩放。
- 图片 Live Text 选择能力以系统 VisionKit 支持为准。
- 点击“识别文字”图标只负责显示 / 隐藏识别高亮，不应关闭预览窗口。
- 预览窗口顶部复制按钮应与主窗口复制一致：普通复制、文件引用复制、文件路径 fallback 和失败结果都有短提示。

## 预览窗口脱离

- 未拖动时，预览窗口仍是附着弹层：显示下方倒三角，跟随当前卡片，主窗口关闭 / 隐藏时一起关闭。
- 只有预览顶部标题栏的标题 / 来源区域可以拖拽脱离；内容区域不能触发脱离，避免影响文本选择、PDF / 图片 / 文件预览操作。
- 用户手动拖动标题栏后，第一次按住拖动就应完成脱离并跟随鼠标移动，不应出现第一次只脱离、第二次才能移动的问题；即使当前激活窗口是微信等其他 App，通过快捷键唤起轻贴并按空格打开预览后，第一次按住预览标题栏也应能直接拖动；主窗口应立刻关闭。
- 主窗口关闭或隐藏后，已脱离的预览窗口不关闭。
- 已脱离预览窗口自身关闭按钮或聚焦时 `Esc` 只关闭该独立预览，不应再次触发主窗口关闭流程；即使焦点落在 Quick Look、PDF、WebView 或文本内容里也应生效。
- 已脱离预览只能由自身关闭按钮关闭，或在该预览窗口聚焦时按 `Esc` 关闭。
- 已脱离预览初始位置应保持在当前屏幕可见区域内，不应跑出屏幕边界；窗口不能被缩到低于 `390x260` 的不可操作尺寸。
- 拖出一个预览窗口后，再次预览任意卡片必须仍按该卡片原位置弹出新的附着预览。
- 每个卡片都可以继续拖出为独立预览窗口，已脱离窗口之间互不影响。
- 预览 header 高度保持原来的紧凑标题栏视觉，不应出现额外大块顶部空白。

## 主窗口基础交互

- 复制新内容后立刻打开轻贴主窗口，新增卡片应被选中并滚动到可见区域。
- 鼠标按住任意卡片拖动时，应先聚焦当前拖动卡片，再启动拖拽。
- 卡片拖出到其他 App 时，应使用整张卡片快照作为拖拽浮层。
- 普通点击、右键菜单、滚轮、预览打开 / 关闭不应被拖拽逻辑误触发。
- 搜索输入快速变化时，主窗口不应因为请求签名比较大量长文本而卡顿；搜索结果语义应与此前一致。
- 大历史量搜索基准应持续通过：1,000 / 10,000 条混合历史记录、中文查询、类型 / 来源过滤、分组排序和 10k source signature 构造均不超过当前守卫阈值。
- 菜单栏“更多”菜单不应再显示“开发测试”；性能测试数据入口仅保留在设置页隐藏入口内。

## 已验证

- `./scripts/build-app.sh --bump minor --run` 通过。
- 当前运行进程存在。
- 预览窗口性能守卫通过：图片、链接、文件等重内容延后加载；PDF 切换时先卸载旧 document；关闭预览时取消待加载任务并先清空 heavy content；内容切换使用轻量 opacity / scale；header、悬浮按钮、OCR badge 和文件列表行使用轻量 hover / press 反馈。
- 预览脱离守卫通过：标题栏标题 / 来源区域拖拽触发脱离；标题栏拖拽热区接收 inactive window 的 first mouse 事件；第一次拖动期间不重建预览内容，避免打断系统窗口拖动；脱离后隐藏倒三角、切换普通窗口层级、主窗口立刻关闭但不误关独立预览；独立预览关闭按钮 / Esc 不重复触发主窗口关闭，且 Esc 在 Quick Look / PDF / WebView / 文本内容焦点内仍应关闭当前脱离窗口；独立预览初始 frame 会约束在屏幕可见区域内，并保留 `390x260` 最小可操作尺寸；拖出后释放附着预览槽位，下一次预览仍从卡片原位置弹出；header 高度维持紧凑布局。
- 预览复制反馈守卫通过：顶部复制按钮会处理 `.copied`、`.copiedFallbackText` 和 `.failed` 三种结果，显示普通复制、文件路径 fallback 或失败原因 toast。
- 搜索性能守卫通过：搜索输入继续走防抖、取消旧任务和后台过滤；搜索请求签名使用每条卡片预生成的 `searchFingerprint`，不再携带整段 `normalizedSearchText`。
- 大历史量搜索基准通过：`scripts/benchmark_history_search_performance.py` 固定生成 1,000 / 10,000 条混合历史样本，常见查询、中文查询、类型 / 来源过滤、分组排序和 10k source signature 构造均低于阈值；当前不触发 SQLite LIKE / FTS / schema 改造门槛。
- 可见调试菜单守卫通过：主窗口菜单不再暴露“开发测试”，设置页隐藏性能测试数据入口仍保留。
- 主窗口启动性能守卫通过：预览列表重建和权限刷新延后到首帧后，后台预热更保守地延迟启动。
- 新增卡片定位守卫通过：最新卡片滚动重试为单个可取消任务，窗口隐藏或定位完成会取消，避免重复重试链叠加。
- 后台资源预热守卫通过：全部卡片继续分批预热，同时与可见卡片加载共享 3 并发资源门，避免抢占 IO / 解码资源。
- 卡片交互动画守卫通过：hover / press 只使用轻量 opacity / scale 状态反馈，松开、移出、右键和拖拽起手都会复位。
- 搜索框动画守卫通过：搜索展开 / 收起的布局状态和视觉状态分离，视觉只动画 opacity / scale，禁止回退到直接动画宽度。
- 搜索按钮回归守卫通过：搜索展开后再次点击搜索按钮会清空并收起，不会被窗口级外点监听先关后开。
- 顶部轨道按钮动画守卫通过：全部剪切板、置顶、用户分组、搜索、新建分组、授权和更多按钮统一使用轻量 hover / press 反馈，不动画宽高或重阴影。
- 音效资源已进入 `.app/Contents/Resources/Sounds/`，复制 / 粘贴反馈静态守卫通过。
- 外部剪贴板捕获成功后会播放 Copy 音效，轻贴自身写入剪贴板的捕获路径不会重复播放。
- 旧的 Quick Look 私有调用崩溃日志没有新增。
- 用户人工确认通过：分组外观 popover、全部剪切板选中 / 未选中视觉、扩展颜色 / 图标选择、搜索展开 / 收起、授权提示和 ESC 关闭顺序均无问题。

## 未自动验证
