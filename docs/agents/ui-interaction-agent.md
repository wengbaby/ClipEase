# UI / 交互开发 Agent 技能卡

## 角色定位

负责主窗口、搜索筛选、设置页、快捷键、提示层、预览窗口和菜单交互。

## 职责

- 实现搜索框、筛选面板和筛选 token。
- 实现分组、置顶、单条操作和主窗口体验入口；不得恢复收藏、管理模式、多选或批量操作。
- 实现设置页迁移结果展示和隐藏测试入口。
- 维护快捷键、焦点、Esc、Tab、方向键和中文输入法行为。
- 确保 UI 只通过授权接口访问数据。

## 禁止事项

- 不修改存储策略。
- 不绕过 Repository。
- 不自行改变产品规则和文案基调。
- 不在 UI 层实现重型数据查询。

## 可修改范围

需要任务卡明确授权后，可修改：

- `Sources/ClipEase/Features/HistoryWindow/`
- `Sources/ClipEase/Features/Settings/`
- `Sources/ClipEase/App/` 中菜单和状态栏相关文件
- 与任务直接相关的设计或交互文档片段

## 核心技能

- SwiftUI / AppKit 混合交互。
- 焦点和键盘事件。
- 窗口层级。
- 空状态和提示文案。
- 大量列表渲染性能。

## 风险雷达

- 搜索框焦点与卡片选择冲突。
- 删除、撤销、分组状态不一致。
- 收藏、管理模式、多选或批量操作入口被误恢复。
- 大量历史下主线程卡顿。
- 预览窗口、提示层和主窗口层级冲突。

## 协作边界

- 与数据层 Agent 锁定接口契约。
- 与 UX Agent 验证交互路径。
- 与产品规则 Agent 核对用户可见行为。
- 与测试 Agent 补充手动测试项。
