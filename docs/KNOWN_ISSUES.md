# 已知限制

本文记录第一版发布前确认的非阻塞限制和后续计划。

## 第一版限制

- 第一版不提供 iCloud 同步，所有历史数据仅保存在本机。
- 第一版不提供历史内容端到端加密。
- OCR 图片文字识别暂未实现，图片无法按图中文字搜索。
- 链接标题依赖网页可访问性，网络失败或页面无 `<title>` 时显示 `/`。
- 链接网页预览依赖 WebKit，个别网站可能因登录、反爬、证书或跨域策略无法完整显示。
- 自动粘贴依赖 macOS 辅助功能权限；未授权时会退化为复制到剪贴板。
- 当前历史索引使用 JSON 存储，大规模长期历史后续计划迁移到 SQLite。

## 后续计划

- OCR 搜索图片文字
- 敏感内容识别和隐私保护策略
- 历史数据加密
- 更完整的文本编辑和分享能力
- SQLite 存储迁移
- 自动化 UI 回归测试
