# 第二版测试计划

## 1. 目标

第二版测试计划用于在正式开发前明确验证范围，避免 SQLite、搜索、分组、备份和文件卡片等核心能力边做边漏。

## 2. 覆盖范围

- SQLite 迁移、主存储切换、迁移失败重建和迁移结果记录。
- Repository 抽象后的历史记录新增、删除、置顶、清理、预览和粘贴。
- 搜索 / 筛选重构，包括多个筛选 token、输入流畅度和完整结果。
- 收藏、取消收藏、分组、更多分组入口、批量管理和空状态。
- SQLite 备份包导出、导入、重复记录处理、附件选择和 Finder 定位。
- 数据健康检查和“一键修复”。
- 敏感 App 忽略、敏感内容遮罩、系统密码或 Touch ID 验证。
- 文件卡片、多文件记录、本地路径展示、Quick Look 预览、路径失效、拖出和再次粘贴。
- 富文本卡片展示和编辑。
- 主窗口、预览窗口、设置页、新建文本窗口和全局提示层的层级与快捷键。

## 3. 执行原则

- 每个第二版阶段开始前补充对应测试用例。
- 高风险数据迁移先做小样本、再做大样本。
- 性能相关测试必须包含 1,000 条和 10,000 条历史数据。
- 文件卡片测试必须覆盖图片、PDF、普通文档、不支持预览文件和路径失效文件。
- 每次功能合并前至少跑 smoke check，并记录无法自动验证的手动测试项。

## 4. 第一阶段重点

- SQLite 数据库创建和迁移。
- 迁移失败清空重建流程。
- 迁移进度和最近 5 次迁移结果。
- JSON 迁移成功后删除。
- 搜索 / 筛选重构前的数据查询性能基线。
