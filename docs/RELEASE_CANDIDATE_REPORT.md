请按 [第一版回归测试清单](./FIRST_VERSION_TEST_CHECKLIST.md) 重点确认：

- 底部主窗口弹出和关闭动画是否稳定流畅。

- 文本、图片、链接预览的打开、关闭、Esc 行为是否符合预期。
- 双击、回车、`Command + 1-9` 是否能粘贴到原 App 光标位置。

- 设置页关闭、保存期限、暂停、权限状态和数据维护入口是否稳定。
