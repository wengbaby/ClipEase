## 本次更新

### 搜索筛选

- 修复选择筛选条件后 token 未在搜索框中显示的问题。
- token 使用独立的左侧滚动轨道，文本输入框固定在右侧，不再互相挤出可视区域。
- 新增 token 或使用键盘切换 token 时，自动保持目标 token 可见。

### 搜索结果操作

- 修复第 21 张及后续搜索结果无法预览、复制、编辑或打开的问题。
- 修复图片和文件无法打开、无法在 Finder 中显示，以及链接无法打开的问题。
- 搜索结果现在保留完整剪贴板实体；只读操作不会扩张主历史内存页，修改操作继续复用既有存储命令。
- 修复删除搜索结果时旧分页请求可能把卡片重新加入列表的竞态。

### 搜索分页

- 修复首批数据库查询读取 50 条、界面仅保留 20 条时，第 21 至 50 条结果被跳过的问题。
- 保持数据库游标偏移、渲染窗口与完整结果实体的一致性。
