## 四、执行计划（按共识）

### 阶段 0：模块化拆分（先做）

1. 建 `HistoryWindow/` 下七域目录结构。
2. 写 `HistoryWindowStateStore` 根 + 5 子 store（Search/Selection/Viewport/Preview/Group）。
3. 分步抽子 View（每步一提交，编译+测试全绿才下一步）：
   - 步骤 1：抽 EmptyContentState/LoadingContentState（无依赖，最简）
   - 步骤 2：抽 SearchField/SearchToken/SearchFilterPanel
   - 步骤 3：抽 Toolbar/TopTrack/ShortcutButtons
   - 步骤 4：抽 GroupButton/GroupAppearancePopover/MoveToGroupPicker
   - 步骤 5：抽 historyRail → HistoryRailView（最复杂，最后做）
   - 步骤 6：抽 Commands（30+ 命令方法）→ HistoryCommands 对象
   - 步骤 7：抽 Menus（CardContextMenu/PauseMenu）
4. 主 `HistoryWindowView.swift` 收缩到 <300 行（只留 body 组装 + StateStore 持有）。
5. 写"模块化拆分记录"文档。

### 阶段 1：Bug1 搜索卡顿修复

1. 先查 `cardDocumentX`（4351行）逻辑，确认能否改流式。
2. `historyRail` 的 `ForEach` + ZStack + offset → `ScrollView` + `LazyHStack` 流式。
3. 重算卡片位置（spacing 取代 offset）。
4. 三重验证：编译 + 测试 + 手动跑 App（100+ 历史连续输入）+ HistoryPerformanceTrace 量化。
5. 写"Bug1 修复记录"文档。

### 阶段 2：Bug2 动画修复

1. 两处 `.linear` → `.easeInEaseOut`（CABasicAnimation 901行 + NSAnimationContext 380行）。
2. `panelAnimationDuration` 0.14 → 0.22。
3. layer animation 的 `Task.sleep` 完成回调 → `CAAnimationDelegate.animationDidStop`。
4. 验证：手动跑 App 观察弹出/收起流畅度。
5. 写"Bug2 修复记录"文档。
