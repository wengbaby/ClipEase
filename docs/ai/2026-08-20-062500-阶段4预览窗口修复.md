## Issue 14：预览动画逐步放大且流畅

### 根因
开 = 单段 scale(0.12,0.04)→identity + opacity；关 = 仅 opacity 无 scale。无逐步放大感。

### 改动点
- `HistoryPreviewWindowController.animatePanelOpen`：改用 CAKeyframeAnimation 多段 scale (0.12,0.04)→(0.5,0.5)→identity，keyTimes [0,0.55,1]，0.34s ease-out-back
- `HistoryPreviewWindowController.close`：加 CAKeyframeAnimation scale identity→(0.85,0.85)→(0.12,0.04)，keyTimes [0,0.5,1]，0.22s ease-in；移除 resetContentBloomLayer（避免禁用动画）

## Issue 15：倒三角与预览体一体化+尖端圆角

### 根因
三角 fill = cardStyle.materialTheme.gradient（opacity=surfaceOpacity*cardEffectOpacity），与预览体（window materialTheme + windowEffectOpacity*0.62）opacity 公式不同 → 视觉脱节；尖端无圆角。

### 改动点
- `HistoryPreviewPopoverView` 三角背景：改为 ZStack { windowBackgroundColor + window materialTheme.gradient.opacity(windowEffectOpacity*0.62) } 与体一致，用 .background+.clipShape(Triangle())
- `Triangle.path`：尖端用 addQuadCurve 圆角（tipRadius=min(4,height/3.5)）

## Issue 16：关主窗时预览同步关闭

### 根因
close() 动画路径在 completionHandler 里才 closePreview() → 串行（主0.22s + 预览0.22s = 0.44s）。

### 改动点
- `HistoryWindowController.close`：在 isClosing=true 后、动画开始前立即调 closePreview()，预览 bloom-close 与主窗动画并行 0.22s 同步结束。completionHandler 里的 closePreview() 保留（幂等）

### 验证
`swift build` + `swift test`（44 个预览测试）全过

### 影响范围
预览窗口开/关动画；倒三角视觉与形状；主窗关闭时序
