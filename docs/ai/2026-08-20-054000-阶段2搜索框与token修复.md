## Issue 2：搜索框展开/关闭动画卡顿掉帧

### 根因
两阶段异步（isFieldLayoutVisible 立即 / isFieldVisualVisible 延迟 Task.sleep 120ms）+ 3 个不同 easeOut 时长（0.12/0.16/0.10）不协调。

### 改动点
- `HistoryWindowView.updateSearchFieldPresentation`：改为单次 `withAnimation(.easeInOut(duration: 0.22))` 同步设 isFieldLayoutVisible + isFieldVisualVisible，删除 Task.sleep 两阶段与 searchVisibilityTask
- `HistorySearchFieldContainer.swift:152`：animation `.easeOut(0.12)` → `.easeInOut(0.22)`
- `HistoryToolbarContainer.swift:196,200`：`.easeOut(0.10)` / `.easeOut(0.16)` → 统一 `.easeInOut(0.22)`

## Issue 5：搜索框展开后浅蓝外边框

### 改动点
- `HistorySearchFieldContainer.swift` 背景 overlay 的 strokeBorder：`Color.white.opacity(boundaryOpacity)`（原仅 increaseContrast 时显）→ `Color(red:0.18,green:0.55,blue:1.0).opacity(isFieldVisualVisible ? 0.5 : 0)` 常驻浅蓝外边框

## Issue 6：放大镜在搜索输入框内部最左侧

### 根因
放大镜原在 ScrollView 内 HStack 最前，与 token 平级，会随 token 增多被滚动。

### 改动点
- `HistorySearchFieldContainer.searchField`：放大镜从 ScrollView 内移出，固定在 HStack 最前（leading），opacity 随 isFieldVisualVisible
- `searchTokenWidthMeasurer`：去掉放大镜测量（只测 token），因放大镜已在外部固定占位

## Issue 7：token 加图标+圆角+选中不闪光标+点空白取消选中

### 改动点
1. `HistorySearchController.HistorySearchTokenKind`：新增 `iconName` 计算属性（type→type.iconName, sourceApp→"app", date→"calendar", group.pinned→"pin.fill", group→"folder.fill"）
2. `searchTokenView`：
   - 加 leading `Image(systemName: token.kind.iconName)` 10pt semibold
   - cornerRadius 6 → 10
   - height 20 → 22，padding 调整
   - 选中 token 时 `isSearchFocused = false; inputState.setTextInputFocused(false)` 隐藏文本光标
   - 再次点击已选中 token 时恢复焦点
3. 搜索框背景 + ScrollView 内的 onTapGesture：增加 `searchUIState.selectedTokenKind = nil`（点空白取消选中 token）
