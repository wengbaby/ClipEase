## 目标与确认规格
1. 预览倒三角完全复用预览主体材质，不使用黑色、独立边框或阴影。
2. 默认展示当前列表第一张；用户点击、键盘移动或手动滚动后，重新打开恢复该选择和横向位置；列表真实新增/删除或切换分组后重置到当前列表最左第一张。
3. 搜索框内容固定为 `[token...][文字输入]`，同一水平行垂直居中；输入可用且光标可见；token 可点击、左右键切换、两次退格删除，输入文字会取消 token 选中。
4. 搜索边框约 4px，并有明显蓝色模糊发光。
5. 从当前分组移除卡片时，不切换到“全部”；只清空 groupID，若移除当前选中卡片则选相邻剩余卡片。

## 根因

### 预览与搜索
- 倒三角使用黑色填充，未和预览主体共享背景材质。
- 搜索 token 选中时会把 `NSTextView.insertionPointColor` 改为透明；自定义 `NSTextFieldCell` 也没有同时处理编辑/选择的垂直绘制区域，导致输入体验异常。
- token 与输入框允许插入到任意 token 间，不符合确认后的固定尾随输入模型。

### 默认选择与滚动恢复
- 默认选择逻辑单独优先挑选置顶项，但视口恢复又基于旧 offset，造成“选中置顶但可见区域展示未置顶项”的不一致。
- 程序滚动与用户滚动共用 offset 保存路径，缺少“用户明确导航”的持久标记。
- 后台从磁盘补页也会改变 `store.items`，不能被误判为系统新增而重置用户视口。

## 实现

### 预览材质
- `HistoryPreviewPopoverView.previewSurface` 作为唯一主体材质：`windowBackgroundColor + materialTheme.gradient`。
- 预览主体背景和 `Triangle` 均复用 `previewSurface`，三角仍向上重叠 1px，避免接缝。

### 搜索输入与 token
- `HistorySearchFieldContainer` 改为固定 `ForEach(token) + SearchTextField`，输入框永远在所有 token 后。
- `SearchTextField` 显式启用 `isEditable/isSelectable/refusesFirstResponder`；移除隐藏插入光标代码。
- `SearchTextFieldCell` 对绘制、编辑和选择区域使用相同的垂直居中 rect。
- 新增 `HistorySearchTokenNavigationPolicy`：左键从文字起点选择最后一个 token，在 token 间左/右移动，最后一个 token 右键回到文字输入。
- 边框调整为 4px，并叠加 14px 主蓝色光晕与 6px 浅蓝内层光晕。

### 列表导航
- `HistoryDefaultSelectionPolicy` 只选当前 `orderedIDs.first`；现有存储排序已保证“全部”中的置顶项位于列表前端。
- 新增 `HistoryOpenNavigationPolicy` 和持久化 `history.hasUserCardNavigation`：仅用户点击、键盘移动和真实滚动后允许恢复选择/offset。
- 新增 `HistoryScrollCoordinator.onUserScroll`，且仅在 offset 相对已保存值有实际变化时触发，程序滚动和初始 0 偏移不会写入用户导航状态。
- 新增 `HistoryOpenNavigationPolicy.shouldResetForMembershipChange`：真实新增/删除重置第一张；`lastPersistedPageItemIDs` 标记后台磁盘补页，避免其改变 ID 集合时重置用户位置。
- 分组切换显式清除用户导航状态、丢弃该 scope 的旧 offset，并在新分组结果就绪后选第一张。

### 移出分组
- `HistoryRemovedItemSelectionPolicy` 在被移除项后优先选后一张，无后一张则选前一张。
- `removeItemFromGroup` 不修改 `selectedGroup`，只执行存储层 groupID 清空和视图同步；移除当前选中项时应用上述相邻选择。
- 用户手动删除使用一次性豁免，保留原有“相邻选择”行为，不被系统成员变化重置规则覆盖。
