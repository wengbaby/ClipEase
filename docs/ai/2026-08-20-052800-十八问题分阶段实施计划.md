## 阶段划分

### 阶段 1：选择与列表类修复（Issue 1, 11）
- Issue 1：改 `latestPresentationCandidate`（HistoryWindowView.swift:3917）和 `primeLatestPresentationGuard`（HistoryWindowFocusState.swift:18）——去掉 `!$0.isPinned` 跳过逻辑，改为 `sourceItems.first`（因排序已是置顶在前）。确保 `applyPendingDefaultFocusOnShowIfNeeded` 走 `filteredItems.first` 不变（已正确）。
- Issue 11：排查卡片移出分组后的刷新链路。store `togglePinned`/`moveToGroup` → 触发 searchController 重跑 → previewItemsState 刷新。重点查 `HistorySearchController` 是否监听 store 变更、`previewItemsState.visibleItems` 是否随 store 更新。
- 验证：`swift build` + `swift test`；写阶段文档。

### 阶段 2：搜索框与 token 修复（Issue 2, 5, 6, 7）
- Issue 2：`HistoryWindowView.updateSearchFieldPresentation`（:2846）改单次 `withAnimation(.easeInOut(0.22))` 同时设 `isFieldLayoutVisible`+`isFieldVisualVisible`，删 Task.sleep。`HistorySearchFieldContainer`(:152) 和 `HistoryToolbarContainer`(:196,200) 的 animation 统一 0.22 easeInOut。
- Issue 5：`HistorySearchFieldContainer` 背景 overlay 的 strokeBorder 改为浅蓝 `Color(red:0.18,green:0.55,blue:1.0).opacity(0.5)` 常驻（不再仅 increaseContrast）。
- Issue 6：放大镜从 ScrollView 内移到 SearchTextField 内部 leading（作为 NSTextField 的 placeholder prefix 或在 SearchTextField 的 HStack 里固定 leading）。
- Issue 7：`searchTokenView`（HistorySearchFieldContainer.swift:223）加 leading 图标（token.kind 对应 SF Symbol）；cornerRadius 6→10；选中 token 时 `inputState.setTextInputFocused(false)` 隐藏光标；输入框背景 onTapGesture 增加 `searchUIState.selectedTokenKind = nil`。
- 验证：编译+测试+阶段文档。

### 阶段 3：卡片视觉修复（Issue 3, 4, 12）
- Issue 3：把 `AppIconCache.dominantColorHex` 接到 `SourceAppInfo.headerColorHex`（或 ClipboardItem.headerColorHex 流路）。中心近白/灰时，向左/右偏移采样（x±8）取第一个非中性色。
- Issue 4：`HistoryCardView.swift:82` clipShape cornerRadius 8→12；`HistoryGlassSurfaces.swift:148,162,166` 同步 12；`HistoryRailContainer.swift:104,128` 同步 12（focus ring 外层 10→14，内层 7→11 保持偏移）。
- Issue 12：`HistoryCardView.swift:60-64` 的 `AsyncSourceIconView` 改为：若 `item.groupID != nil`，用分组图标 + 分组色（从 groupAppearanceCoordinator 取）；否则用源应用图标。
- 验证：编译+测试+阶段文档。

### 阶段 4：预览窗口修复（Issue 14, 15, 16）
- Issue 14：`HistoryPreviewWindowController.animatePanelOpen`（:168）改用 CAKeyframeAnimation 多段 scale（0.12→0.5→1.0）；`close`（:270）加 scale 1→0.85→0.12 keyframes。
- Issue 15：`HistoryPreviewPopoverView.Triangle`（:826）fill 改为 `Color(nsColor:.windowBackgroundColor)` + `appearanceSettings.materialTheme.gradient.opacity(windowEffectOpacity*0.62)`（与体一致）；path 尖端用 `addQuadCurve` 圆角半径 4。
- Issue 16：`HistoryWindowController.close`（:392）动画路径里，把 `closePreview()` 从 completionHandler 移到动画开始处（与主窗动画并行）。
- 验证：编译+测试+阶段文档。

### 阶段 5：功能行为修复（Issue 8, 9, 10, 13）
- Issue 8：删 HistoryWindowView 顶部 close 按钮（找 xmark circle 按钮），只留图标+文字。
- Issue 9：`AppMenuController.createTextItem`（:71-95）保存后加 `pasteExecutor.copyTextToPasteboard(plainText)`。
- Issue 10：深查 PasteExecutor.pasteToFrontmostApp 时序——`previousFrontmostApplication` 捕获时机、`hideImmediatelyForAutoPaste` 后 120ms 是否够目标 app 重获焦点、CGEvent 是否被吞。必要时加诊断日志先复现。
- Issue 13：`MoveToGroupPickerView`（:30）LazyVStack→LazyVGrid 横排；每行背景=分组色；项间 Divider。

### 阶段 6：状态栏倒计时（Issue 17）
