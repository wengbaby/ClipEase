## 本次更新

### 窗口与动画

- 使用单一 presentation plan 统一新卡片选择与视口定位。
- 修复存在置顶卡片时，主窗口每次打开都会重复横向移动到新卡片的问题。
- 隐藏期间新增卡片后，下一次打开直接展示目标位置；窗口已显示时只执行一次平滑滚动。
- 关闭窗口改为稳定 content-layer 动画，减少 live window frame 布局开销。
- 预览倒三角与窗口主体使用一致材质，并改进分离窗口拖拽与动画锚点。

### 搜索

- 修复中文连续文本的子串搜索，例如内容包含“侧悬浮窗口、迷你窗口、主窗口”时，可使用“窗口”“窗”“口”命中。
- 搜索结果取消卡片结构动画，每次搜索只重置一次视口。
- 输入框原生即时回显，SwiftUI 状态合并提交，减少整棵窗口视图重建。
- 优化 token 键盘导航、应用图标显示、垂直对齐、边框与发光效果。
- 减少重复 frame 测量、资源预热、本地化读取和 AppKit 控件重配置。

### 卡片与分组

- 默认选择当前列表第一张卡片，保持用户明确选择和滚动位置。
- 修复卡片移出分组时错误切换到“全部”的问题；当前选中卡片移出后选择相邻卡片。
- 固定卡片头部高度，增强分组颜色与图标表现。
- 修复大量卡片首次绑定时只显示首批内容的问题。

### 其他改进

- 优化来源应用图标取色与缓存失效策略。
- 改进预览、复制、粘贴、状态栏倒计时和剪贴板空闲轮询。
- 增加窗口呈现、中文搜索、分组变更和性能预算回归测试。

## 验证

- 严格 Swift 6 并发 release 编译通过。
- 窗口、搜索、SQLite、中文子串和性能相关测试通过。
- 10,000 条记录下中文单字子串搜索通过性能预算。
- DMG、SHA-256 和 GitHub 上传校验由发布脚本生成并追加到正式 Release 正文。
