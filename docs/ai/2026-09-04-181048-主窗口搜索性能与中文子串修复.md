## 本轮目标

1. 修复置顶卡片存在时，新卡片在每次开窗后重复横移的问题。
2. 降低搜索、开窗和关窗的布局与动画卡顿。
3. 修复连续中文文本无法按中间子串搜索的问题，例如内容包含“侧悬浮窗口、迷你窗口、主窗口”时，“窗口”“窗”“口”都必须命中。

## 实现

### 单一呈现计划

- 新增 `HistoryPresentationPlanner`，统一输出 selection、viewport intent、scope reset、latest focus 消费和 entrance animation。
- 新卡片不再由 `store.items` 变化推断；只使用显式 `latestItemFocusRequest`，消除双事件源。
- 隐藏期间新增：Controller 在 panel order 前排队最终 offset，View 首次挂载幂等消费 plan；不播放横向滚动或卡片 entrance 动画。
- 窗口已显示时新增：只产生一次 animated item viewport intent，entrance 动画延后到横向滚动后。
- scope/search 重置与 viewport intent 串行，使用一次性 suppression 防止分组 onChange 把目标 offset 覆盖为 0。

### 搜索主线程优化

- 搜索结果 rail 取消插入、移除和缩放动画；每个搜索 presentation 只重置一次 viewport。
- 搜索活跃期间暂停非必要 asset preheat。
- `SearchTextField` 原生即时显示输入，SwiftUI 文本状态按 60ms 合并提交；编辑期间不被旧 binding 回写。
- 移除隐藏 token 重复测量树和 toolbar 整体布局动画。
- SearchInteraction frame 只保留 AppKit 屏幕坐标通道，并对 0.5px 内重复 frame 去重。
- `SearchTextFieldCell` 使用字体高度计算垂直绘制区域，不再在 layout 中调用昂贵 `cellSize(forBounds:)`。

### 静态资源与窗口动画

- 缓存 ClipEase 应用图标的读取、尺寸变换和圆角结果。
- `MoreMenuButton` 静态属性只在 make 时配置。
- AppLocalization 缓存语言偏好和 preferredLanguages，不再每次 `L()` 读取 UserDefaults/Locale。
- 关闭窗口改为固定 frame 的 content-layer translation。
- Instruments 实测发现整层 rasterization 会增加首次合成 microhang，因此已撤销 rasterization，只保留稳定 layer 动画。

### 中文子串搜索

- 根因：FTS5 `unicode61` 对连续中文形成大 token，现有 `"query"*` 仅支持 token 前缀，不能命中 token 中间的“窗口”“窗”“口”。
- 英文、数字和普通分词查询继续使用 FTS5 前缀索引。
- 包含中日韩字符的查询在 SQLite search index 的 `search_text` 上使用规范化 `instr` 子串匹配。
- 类型、来源 App、置顶、分组过滤、稳定排序、offset 和 cursor 分页仍在数据库层执行。

## 验证

- 新增 `HistoryPresentationPlannerTests`：hidden insert、visible insert、repeated open、default open、final offset。
- 新增真实 SQLite 中文连续文本测试，验证“窗口”“窗”“口”均命中且无关卡片不命中。
- 新增 10k 条中文单字搜索性能预算，耗时低于 1.5 秒门槛。
- 160 项窗口、搜索、SQLite、性能相关测试通过。
- 严格 release 编译通过：`strict-concurrency=complete + warnings-as-errors`。
- 代码审查发现并修复 scope reset 覆盖 target offset、首次挂载顺序、双 frame reader 和本地化重复读取。
- 全量测试曾被既有长时间 helper 卡住；隔离审查环境报告 580 项通过，定向套件已在当前工作树复验。

## 影响范围

- `Features/HistoryWindow`：presentation、viewport、搜索输入/结果、toolbar、close animation。
- `Core/Storage/SQLite`：CJK substring search 策略。
- `App/ClipEaseAppIcon`、`Core/Settings/AppLanguageSettings`：静态资源缓存。
- 无数据库 schema 迁移、无新增依赖、无卡片排序变化。
